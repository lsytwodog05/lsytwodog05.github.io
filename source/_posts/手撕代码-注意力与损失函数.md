## 一、Self-Attention

**公式**：$\text{Attention}(Q,K,V)=\text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$

**原理**：每个 token 用 Query 去和所有 Key 算相似度，再按权重聚合 Value。除以 $\sqrt{d_k}$ 是为了防止高维点积过大，导致 Softmax 饱和、梯度消失。

```python
import math
import torch
import torch.nn as nn


class SelfAttention(nn.Module):
    def __init__(self, embed_dim):
        super().__init__()
        self.embed_dim = embed_dim
        self.W_q = nn.Linear(embed_dim, embed_dim)
        self.W_k = nn.Linear(embed_dim, embed_dim)
        self.W_v = nn.Linear(embed_dim, embed_dim)

    def forward(self, x):
        # 输入 x: [B, L, embed_dim]  batch，序列长度，特征维度
        Q = self.W_q(x)
        K = self.W_k(x)
        V = self.W_v(x)

        # Q @ K^T → [B, L, L]
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.embed_dim)
        attn_weight = torch.softmax(scores, dim=-1)
        return torch.matmul(attn_weight, V)
```

**易错点**：

- Softmax 必须在最后一维（对「所有 Key」归一化）。
- 缩放用的是 $d_k$，不是序列长度 $L$。

**为什么要缩放**：

- 高维下点积会把分数拉得差距巨大。
- Softmax 遇到差距很大的输入，输出接近 one-hot，梯度消失。
- 除以 $\sqrt{d_k}$ 把分数缩放回标准差约为 1，Softmax 输出更平滑，梯度可以正常学习。

## 二、Cross-Attention

**与 Self-Attention 的区别**：Q 来自一个序列，K/V 来自另一个序列。

| 对比 | Self-Attention | Cross-Attention |
| :--- | :--- | :--- |
| 输入 | 同一个 `x` | `x_q`（Query 源）+ `x_kv`（Key/Value 源） |
| 典型场景 | Encoder / Decoder 自注意力 | Decoder 去看 Encoder 输出 |
| scores 形状 | `[B, L, L]` | `[B, L_q, L_kv]` |

```python
import math
import torch
import torch.nn as nn


class CrossAttention(nn.Module):
    def __init__(self, embed_dim):
        super().__init__()
        self.embed_dim = embed_dim
        self.W_q = nn.Linear(embed_dim, embed_dim)
        self.W_k = nn.Linear(embed_dim, embed_dim)
        self.W_v = nn.Linear(embed_dim, embed_dim)

    def forward(self, x_q, x_kv):
        # x_q:  [B, L_q, D]   Query 来源（如 decoder 当前序列）
        # x_kv: [B, L_kv, D]  Key/Value 来源（如 encoder 输出）
        Q = self.W_q(x_q)
        K = self.W_k(x_kv)
        V = self.W_v(x_kv)

        # scores: [B, L_q, L_kv]
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.embed_dim)
        attn_weight = torch.softmax(scores, dim=-1)
        return torch.matmul(attn_weight, V)
```

**要点**：后面两步（Softmax + 加权求和 V）和 Self-Attention 完全一样，区别只在「Q 与 K/V 是否同源」。

## 三、Multi-Head Attention

把 `d_model` 切成 `num_heads` 个头，每个头独立算注意力，再拼回并做输出投影。

**关键维度变换**：

| 步骤 | shape | 作用 |
| :--- | :--- | :--- |
| `view` | `[B, L, H, d_k]` | 把特征维切成多个头 |
| `transpose(1,2)` | `[B, H, L, d_k]` | 让 `matmul` 把 `B,H` 当 batch，并行算所有头 |
| `transpose` + `contiguous().view` | `[B, L, d_model]` | 拼回头；`transpose` 后内存不连续，必须先 `contiguous()` |

```python
import math
import torch
import torch.nn as nn


class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, num_heads):
        super().__init__()
        assert d_model % num_heads == 0
        self.d_model = d_model
        self.num_heads = num_heads
        self.d_k = d_model // num_heads

        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)

        self.cache_k = None
        self.cache_v = None

    def forward(self, x, mask=None, use_cache=False):
        B, L, D = x.shape
        Q = self.W_q(x)
        K = self.W_k(x)
        V = self.W_v(x)

        # [B, L, D] → [B, H, L, d_k]
        Q = Q.view(B, L, self.num_heads, self.d_k).transpose(1, 2)
        K = K.view(B, L, self.num_heads, self.d_k).transpose(1, 2)
        V = V.view(B, L, self.num_heads, self.d_k).transpose(1, 2)

        # KV Cache：自回归推理时复用历史 K/V，避免重复计算
        if use_cache:
            if self.cache_k is not None:
                self.cache_k = torch.cat([self.cache_k, K], dim=2)
                self.cache_v = torch.cat([self.cache_v, V], dim=2)
            else:
                self.cache_k, self.cache_v = K, V
            K, V = self.cache_k, self.cache_v

        # scores: [B, H, L_q, L_k]
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_k)

        if mask is not None:
            scores = scores.masked_fill(mask == 0, float("-inf"))

        attn = torch.softmax(scores, dim=-1)
        out = torch.matmul(attn, V)

        # [B, H, L, d_k] → [B, L, D]
        out = out.transpose(1, 2).contiguous().view(B, L, D)
        return self.W_o(out)

    def clear_cache(self):
        self.cache_k = None
        self.cache_v = None
```

### 为什么必须 `transpose(1, 2)`？

`view(B, L, H, d_k)` 之后 shape 为 `[B, L, H, d_k]`，各维含义：

- `B`：批次
- `L`：token 序列长度
- `H`：第几头
- `d_k`：这个头内部的特征维

**如果不做 transpose**，直接 `matmul(Q, K^T)`：

- `Q`：`[B, L, H, d_k]`
- `K.transpose(-2, -1)`：`[B, L, d_k, H]`
- 最后两维相乘：`(H, d_k) @ (d_k, H)` → `[B, L, H, H]`

这完全不是我们想要的。目标是**每个头独立做注意力**，而不是把「头」当成参与矩阵相乘的特征维。

**做完 `transpose(1, 2)` 之后**：shape 变成 `[B, H, L, d_k]`

- 0 维 `B`：batch
- 1 维 `H`：注意力头（放到靠前）
- 2 维 `L`：query 序列长度
- 3 维 `d_k`：每个头的特征向量

此时：

- `Q`：`[B, H, L, d_k]`
- `K.transpose(-2, -1)`：`[B, H, d_k, L]`
- 每个头：`[L, d_k] @ [d_k, L]` → `[L, L]`
- 输出 `scores`：`[B, H, L, L]`

`torch.matmul` 会把前面的 `B、H` 全部当成批量维，只对最后两维做矩阵运算，从而一次性并行算完所有头。

**面试常问**：

- 为什么要多头？不同头可以关注不同子空间（句法、位置、语义等）。
- 为什么 `transpose` 后要 `contiguous()`？`view` 要求内存连续，`transpose` 只改 stride。
- KV Cache 缓存的是投影后的 K/V，不是原始 `x`。

## 四、二元交叉熵（BCE）

**公式**：

$$
\mathcal{L}=-\frac{1}{N}\sum_{i=1}^{N}\Big[y_i\log\hat{y}_i+(1-y_i)\log(1-\hat{y}_i)\Big]
$$

$y=1$ 时只剩 $-\log\hat{y}$；$y=0$ 时只剩 $-\log(1-\hat{y})$。用 $y$ 与 $(1-y)$ 当选择器，一行写完两种情况。

```python
import numpy as np


def binary_cross_entropy(y_pred, y_true, eps=1e-10):
    """
    y_pred: 概率, [0,1]
    y_true: 标签, {0,1}
    """
    y_pred = np.array(y_pred).flatten()
    y_true = np.array(y_true).flatten()

    # 防止 log(0) → -inf / NaN
    y_pred = np.clip(y_pred, eps, 1 - eps)

    loss = -np.mean(
        y_true * np.log(y_pred) + (1 - y_true) * np.log(1 - y_pred)
    )
    return loss
```

**要点**：调用前需保证 `y_pred` 已过 Sigmoid；`clip` 是数值稳定的关键。

## 五、Softmax

**公式**：$\text{softmax}(x_i)=\frac{e^{x_i}}{\sum_j e^{x_j}}$

直接算 $e^{x}$ 容易溢出。利用恒等式：所有 logits 同减常数结果不变，取 $C=\max(x)$：

$$
\text{softmax}(x_i)=\frac{e^{x_i-C}}{\sum_j e^{x_j-C}}
$$

```python
import torch


def softmax(x: torch.Tensor, dim: int = -1) -> torch.Tensor:
    x_max = x.max(dim=dim, keepdim=True).values
    x_exp = torch.exp(x - x_max)
    return x_exp / x_exp.sum(dim=dim, keepdim=True)
```

**要点**：

- `keepdim=True` 方便广播，不用手动 `unsqueeze`。
- 默认 `dim=-1`，因为最后一维通常是类别维。

**`keepdim` 为什么重要**：

```python
import torch

# x shape [2, 3]
x = torch.tensor([[1., 9., 3.], [4., 2., 7.]])

# ❶ keepdim=False，输出 shape [2]
max_no_keep = x.max(dim=1).values
# x: [2,3]  max_no_keep: [2]
# x - max_no_keep  → 广播失败，维度不匹配！

# ❷ keepdim=True，输出 shape [2,1]
max_keep = x.max(dim=1, keepdim=True).values
# x: [2,3]  max_keep: [2,1]
diff = x - max_keep  # ✅ 广播正常
print(diff)
# tensor([[-8.,  0., -6.],
#         [ 0., -2.,  3.]])
```

## 六、AUC

> 随机抽 1 个正样本、1 个负样本，**模型给正样本打更高分的概率**。

AUC 只看相对排序，不看绝对分数；对类别不平衡更鲁棒（Accuracy 在 999 负 + 1 正时会虚高）。

### 正负对暴力统计

复杂度 $O(N^2)$，直接对应物理含义，适合面试手写。

```python
import numpy as np


def cal_auc(y_pred, y_true):
    y_pred = np.asarray(y_pred)
    y_true = np.asarray(y_true)
    correct, total = 0, 0

    for i in range(len(y_true) - 1):
        for j in range(i + 1, len(y_true)):
            if y_true[i] == y_true[j]:
                continue  # 只统计一正一负
            total += 1
            # 标签大小关系与预测分大小关系一致 → 排对了
            if (y_true[i] - y_true[j]) * (y_pred[i] - y_pred[j]) > 0:
                correct += 1

    return correct / total if total > 0 else float("nan")
```

**易错点**：

- AUC $< 0.5$ 时，先检查正负标签是否写反。
- 分数整体乘以常数，AUC 不变（只看排序）。
- AUC 高 ≠ 某个业务阈值下的 TPR/FPR 一定满足要求。

## 七、KL 散度

**公式**：$D_{KL}(P\|Q)=\sum_i P(i)\log\frac{P(i)}{Q(i)}$

衡量用 $Q$ 近似 $P$ 时多出的信息损失。注意：**不对称**，$D_{KL}(P\|Q)\neq D_{KL}(Q\|P)$。

```python
import torch


def kl_divergence(p: torch.Tensor, q: torch.Tensor, eps: float = 1e-10) -> torch.Tensor:
    """
    p: 真实分布（已归一化）
    q: 近似分布（已归一化）
    """
    p = p + eps
    q = q + eps
    return (p * torch.log(p / q)).sum()
```

**要点**：

- 输入必须是概率分布（非负且和为 1），通常先 Softmax。
- 加 `eps` 避免 `log(0)` 和 `0 * (-inf) = nan`。
- PyTorch 里更常用 `F.kl_div`，注意它默认接收 **log-probabilities**。

## 八、NDCG

NDCG（Normalized Discounted Cumulative Gain）是一种**位置敏感**的排序指标，更关心：高相关内容有没有被排到越靠前的位置。

### 为什么需要 NDCG？

在搜索 / 推荐 / 排序里，用户通常只看前几条，**位置越靠前，影响越大**。AUC 只关心相对顺序，不直接惩罚「相关结果排太靠后」；NDCG 通过位置折扣把这一点显式建模进去。

### 公式

$$
NDCG@K = \frac{DCG@K}{IDCG@K}
$$

- **DCG**：模型当前排序的得分
- **IDCG**：理想排序（相关性从高到低）的得分
- $NDCG \in [0,1]$，越大越好

### DCG

$$
DCG@K=\sum_{i=1}^{K}\frac{2^{rel_i}-1}{\log_2(i+1)}
$$

- $i$：位置（从 1 开始）
- $rel_i$：第 $i$ 个结果的相关性（如 $0/1/2/3\ldots$）
- $\log_2(i+1)$：位置越靠后，贡献越小，模拟用户注意力衰减

### IDCG

把同一批结果按相关性从高到低重排，再算一遍 DCG，就是 IDCG。NDCG 用它做归一化，方便跨 query / 跨样本比较。

```python
import math


def dcg_at_k(relevance, k):
    """
    relevance: 按「模型排序顺序」给出的相关性列表
    公式里位置 i 从 1 开始；Python 下标从 0 开始，
    所以分母要用 log2(i + 2)：i=0 → log2(2)=1
    """
    n = min(k, len(relevance))
    dcg = 0.0
    for i in range(n):
        rel = relevance[i]
        dcg += (2 ** rel - 1) / math.log2(i + 2)
    return dcg


def ndcg_at_k(relevance, k):
    # IDCG：理想排序 = 相关性降序后再算 DCG
    idcg = dcg_at_k(sorted(relevance, reverse=True), k)
    dcg = dcg_at_k(relevance, k)
    if idcg == 0:
        return 0.0
    return dcg / idcg
```

**易错点**：

- 公式位置从 1 起算；代码若写成 `log2(i + 1)` 且 `i` 从 0 开始，第一项会 `log2(1)=0` **除零**。
- `relevance` 必须是**模型排序后的相关性序列**，不是按分数乱序的标签列表。
- 全为 0 相关时 IDCG=0，约定返回 0，避免除零。
