优化器本质上是在做同一件事：**沿着损失函数下降最快的方向更新参数**。区别在于「每次用多少数据」、「走多大的步长」以及「如何更聪明地走」。

## 基础梯度下降

**1. BGD（全批量梯度下降）**

- 每次用**全部样本**计算梯度，更新一次参数。
- 优点：梯度方向最准确；缺点：极慢，无法处理大数据集，容易陷入局部最优点。

**2. SGD（随机梯度下降）**

- 每次只用**1 个样本**计算梯度，更新一次参数。
- 优点：极快，能逃离局部最优；缺点：梯度噪声大，震荡严重，收敛不稳定。

**3. MBGD（小批量梯度下降）**

- 每次用**一个 Batch**（如 256、512）计算梯度。
- 兼具 BGD 的准确性和 SGD 的速度，配合 GPU 矩阵运算效率最高。

> Batch Size 是关键超参数。太大容易陷入尖锐局部最优（泛化差），太小梯度噪声过大、收敛慢。通常取 32~512 之间的 2 的幂次。

## 动量法

SGD 在梯度方向变化剧烈时（如峡谷地形）会左右震荡，收敛缓慢。**动量（Momentum）** 引入物理「惯性」概念，让更新方向不仅依赖当前梯度，还依赖上一次更新的方向。

**公式**：

```text
v_t = β * v_{t-1} + η * ∇L(θ_{t-1})
θ_t = θ_{t-1} - v_t
```

- 通常 β = 0.9。

**NAG（Nesterov Accelerated Gradient）**：

- 先按当前速度走一步，再在那个位置算梯度。
- 公式：

```text
v_t = β * v_{t-1} + η * ∇L(θ_{t-1} - β * v_{t-1})
```

- 效果：能提前感知前方地形变化，防止冲过头，收敛速度通常快于标准动量。

## 自适应学习率家族

### AdaGrad：梯度平方累加，让学习率衰减

- 对每个参数维持一个**历史梯度平方和**，学习率除以该和的平方根。
- **效果**：频繁更新的参数学习率下降快，稀疏更新的参数学习率下降慢。适合稀疏数据（如 NLP）。
- **缺点**：梯度平方和会持续累加，导致学习率趋近于 0，最终完全停止学习。

### RMSprop：引入指数衰减，解决 AdaGrad 的「早停」问题

- 用**指数加权移动平均（EWMA）** 替代累加和，只关注最近一段时间的梯度大小。

```text
v_t = β * v_{t-1} + (1 - β) * (∇L)^2
θ_t = θ_{t-1} - η / sqrt(v_t + ε) * ∇L
```

- 常取 β = 0.999，ε = 1e-8（防除零）。
- 效果：学习率不会单调递减至 0，能持续学习。

### Adam

- **一阶矩（m）**：梯度的指数加权平均（类似动量，估计平均梯度方向）。
- **二阶矩（v）**：梯度平方的指数加权平均（类似 RMSprop，估计梯度方差/尺度）。
- **偏差修正（Bias Correction）**：由于 m 和 v 初始为 0，在前期会偏向 0，通过 `/(1-β^t)` 做放缩，加快冷启动。

**Adam 完整公式（面试手写）**：

```text
m_t = β1 * m_{t-1} + (1 - β1) * g_t          # 一阶矩估计
v_t = β2 * v_{t-1} + (1 - β2) * g_t^2        # 二阶矩估计
m_hat = m_t / (1 - β1^t)                      # 偏差修正
v_hat = v_t / (1 - β2^t)
θ_t = θ_{t-1} - η * m_hat / (sqrt(v_hat) + ε)
```

- 默认 β1=0.9，β2=0.999，ε=1e-8。
- Adam 是目前工业界**默认首选**优化器，鲁棒性极强，对超参数不敏感，几乎适用于所有场景。


## AdamW

**问题根源**：

- 在传统 SGD 中，**L2 正则化（权重衰减）** 和 **损失函数加 L2 项** 是等价的。
- 但在 Adam 中，两者**不等价**。因为 Adam 对每个参数有自适应学习率，在损失函数中加入 L2 项（即 `Loss + λ||θ||²`）计算梯度时，梯度项包含 `2λθ`，但这个梯度会被 `sqrt(v)` 除，导致**真正对参数的衰减效果被自适应学习率破坏了**——高频特征衰减弱，低频特征衰减强，与 L2 正则化的初衷（所有权重同比例衰减）违背。

**AdamW 的解决方案**：

- **移除**损失函数中的 L2 正则化项。
- **显式**在参数更新时做权重衰减：

```text
θ_t = θ_{t-1} - lr * m_hat/(sqrt(v_hat)+ε) - lr * λ * θ_{t-1}
```

- 将权重衰减与损失函数解耦，保证所有参数均匀衰减。

> **结论**：使用 Adam 时若需要 L2 正则化，请务必使用 **AdamW** 替代 Adam，尤其在 Transformer（BERT、GPT）训练中，AdamW 是默认标配。


| 对比维度 | **SGD + Momentum / NAG** | **Adam / AdamW** |
| :--- | :--- | :--- |
| **收敛速度** | 慢，需要精细调节学习率 | **快**，自适应调节，开箱即用 |
| **泛化能力（测试集表现）** | **更好**，能收敛到更平坦的极小值 | 易收敛到尖锐极小值，泛化稍差 |
| **对超参数的敏感度** | 极高（学习率、动量系数需精细调参） | 极低，默认参数通常表现良好 |
| **内存占用** | 小（只存速度 v） | 大（需存 m 和 v 两个状态，参数量翻倍） |
| **最优适用场景** | CV 图像分类、需要极致泛化性能时 | **NLP（Transformer）、大规模推荐、GAN** 等大多数工业场景 |

**为什么 SGD 泛化更好？**

- 主流理论认为，Adam 的自适应学习率会引入额外的随机噪声，或者让模型快速收敛到损失面的**尖锐极小值**；而 SGD 的噪声更大，会推动模型走向**平坦极小值**，在测试集上更稳定。


## 面试题集合

1. **Adam 的偏差修正在做什么？**  
   答：因为 m 和 v 初始化全 0，初期迭代时它们严重偏向 0（尤其是 v 很小导致学习率极大）。除以 `(1-β^t)` 可以放缩回正确尺度。随着 t 增大，`1-β^t` 趋近 1，修正失效，回归正常。

2. **Adam 的参数 β1、β2 分别控制什么？**  
   答：β1（通常 0.9）控制一阶矩（平均梯度）的衰减速度，越大越依赖历史方向（平滑）。β2（通常 0.999）控制二阶矩（梯度方差）的衰减速度，越大对历史梯度平方的记忆越长（学习率变化更平滑）。

3. **为什么 AdaGrad 不适合训练深度神经网络？**  
   答：因为学习率单调递减最终趋于 0，导致模型无法继续学习。

4. **RMSprop 相对于 AdaGrad 改进了什么？**  
   答：用指数加权移动平均替换梯度平方累加，使学习率不会单减，能持续适应最新的梯度尺度。

5. **AdamW 相对于 Adam 改进了什么？**  
   答：将 L2 正则化从损失函数中剥离，变为独立的权重衰减项，确保在高频和低频特征上同比例衰减，而非受自适应学习率干扰。


## 学习率调度

优化器通常还需配合学习率调度策略：

- **Step Decay**：每隔固定轮次，学习率乘以一个衰减因子（如 0.1）。
- **Cosine Annealing**：学习率按余弦周期从大到小变化，配合重启（Warm Restart）效果更好。
- **Warmup**：训练前若干轮（如 10% 的 steps），学习率从 0 线性上升到目标值。常用于 Transformer 和大型模型，防止早期梯度震荡。
- **ReduceLROnPlateau**：当验证集指标不再提升时，自动降低学习率（PyTorch 内置）。
